## 4. Тестирование NER и PII-деидентификации

### Тестовый текст

```
Пациент Иванов Иван Иванович, дата рождения 15.03.1980,
поступил в отделение кардиологии с диагнозом гипертония.
```

### Результат extract_pii

| Сущность | Тип | Confidence |
|---|---|---|
| Иванов | first_name | 0.853 |
| Иван | first_name | 0.909 |
| Иванович | last_name | 0.707 |
| 15.03.1980 | date | 0.946 |

Используемая модель: `OpenMed/OpenMed-PII-SuperClinical-Small-44M-v1`

### Результат deidentify

```
Оригинал:
Пациент Иванов Иван Иванович, дата рождения 15.03.1980, поступил в отделение кардиологии с диагнозом гипертония.

После деидентификации:
Пациент [first_name][last_name] [first_name] [last_name], дата рождения [date], поступил в отделение кардиологии с диагнозом гипертония.
```

## 6. Модели для русскоязычных медтекстов

OpenMed не имеет отдельных русскоязычных моделей, однако **многоязычные модели серии SuperClinical успешно обрабатывают русский текст**. Рекомендуемые модели:

| Модель | Размер | Рекомендация |
|---|---|---|
| `OpenMed-PII-SuperClinical-Small-44M-v1` | 44M | ✅ Рекомендуется для задач OM-2–OM-5 (баланс скорости и точности) |
| `OpenMed-PII-SuperClinical-Base-184M-v1` | 184M | Для повышенной точности |
| `OpenMed-PII-SuperClinical-Large-434M-v1` | 434M | Максимальная точность, медленнее |

**Выбранная модель для OM-2–OM-5:** `OpenMed/OpenMed-PII-SuperClinical-Small-44M-v1`
